# Dalton Team

Site do treinador Dalton da Silva Souza, com logo, fotos, serviços e contato.

Site publicado: https://daltonteam.pages.dev/

## Arquivos

Site estático em `index.html`. Fotos em `images/` e estilos e fontes em `_next/static/`. Todos os recursos visuais estão incluídos, sem depender da Vercel. Os links de contato levam ao WhatsApp e Instagram.

## Visualização

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP local. Não requer instalação de dependências nem compilação.

## Publicação

A publicação atual na Cloudflare Pages foi feita por upload manual. Este repositório ainda não possui deploy automático. Para atualizar, envie os arquivos do site em um novo deployment no projeto Cloudflare existente; o `index.html` deve estar na raiz do upload.

Esta versão foi recuperada do HTML público do site e adaptada com o logo aprovado e menu móvel. Não contém o código-fonte original React/Next.js do v0.
